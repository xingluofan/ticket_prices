# 机票价格爬取与分析系统

## 📁 文件结构与作用

| 文件/目录              | 作用                                                                                                                                            |
| :--------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------- |
| `app.py`               | **核心后端服务**。基于 Flask，负责启动 Web 服务器，提供 API 接口（获取城市、运行爬虫脚本、读取数据库），并托管前端页面。                        |
| `index.html`           | **可视化前端页面**。使用 Vue 3 + Element Plus 构建，提供城市选择、数据筛选（出发地/目的地/日期/平台）、更新数据操作界面及实时日志展示。         |
| `feizhu.py`            | **Feizhu 爬虫脚本**。负责爬取 Feizhu 平台的机票价格数据，支持多线程或单次爬取，数据存入 `feizhu_info.sqlite`。                                  |
| `xiecheng.py`          | **Xiecheng 爬虫脚本**。负责爬取 Xiecheng 平台的机票价格数据，数据存入 `xiecheng_info.sqlite`。                                                  |
| `XC_spider.py`         | **爬虫核心逻辑库**。包含请求签名生成（Sign）、Token 获取（`_m_h5_tk`）、Cookie 管理等核心反爬虫处理逻辑，供 `feizhu.py` 和 `xiecheng.py` 调用。 |
| `common/`              | **公共模块目录**。包含数据库操作 (`database.py`) 和城市代码映射 (`city_code.py`) 等通用工具。                                                   |
| `feizhu_info.sqlite`   | **Feizhu 数据库**。SQLite 数据库文件，存储 Feizhu 的航班价格数据。                                                                              |
| `xiecheng_info.sqlite` | **Xiecheng 数据库**。SQLite 数据库文件，存储 Xiecheng 的航班价格数据。                                                                          |

## 🚀 启动方式

### 1. 环境准备

确保已安装 Python 3.x，并安装所需依赖：

```bash
pip install flask requests fake-useragent
```

### 2. 启动服务

在终端运行以下命令启动 Flask 服务器：

```bash
python3 app.py
```

服务启动后，终端会显示访问地址，默认为：`http://127.0.0.1:5001`

### 3. 使用系统

1.  **访问页面**：在浏览器打开 `http://127.0.0.1:5001`。
2.  **查看数据**：页面会自动加载已有的数据库数据，支持按城市、日期范围和平台筛选。
3.  **更新数据**：
    - 点击右上角的 **“更新 Feizhu 数据”** 或 **“更新 Xiecheng 数据”** 按钮。
    - 在弹出的对话框中选择需要爬取的城市（支持搜索和多选）。
    - 点击 **“开始更新”**，右侧抽屉会弹出并实时显示爬虫运行日志。
    - 更新完成后，页面表格会自动刷新展示最新数据。

## ⚠️ 注意事项

- **反爬虫机制**：如果遇到数据获取失败，通常是因为触发了平台的反爬虫机制（如滑块验证）。此时建议稍后重试，或减少单次选择的城市数量。
- **Cookie**：项目已内置自动获取 Token 的逻辑，无需手动抓包填写 Cookie。
